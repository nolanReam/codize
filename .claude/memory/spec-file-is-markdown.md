# The master spec is a Markdown file, not a PDF

`docs/context/codize_master_spec_v2.1.md` is the authoritative spec. Older references (spec-guardian SKILL.md, early instructions.md) point to `codize_master_spec_v2.1.pdf`, which does not exist.

Why it matters: a session that trusts the `.pdf` path will conclude the spec is missing. Also: `docs/context/conversations.json` is ~1.4MB — grep it, never read it whole.
