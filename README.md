# Codize

Codize is a beginner-first AI coding mentor for students building real projects with external coding agents. Its V2 promise is: **Build something real with AI. Learn how it works as you go.**

V2 is currently a canonical product/UX direction, not an implemented architecture. The repository still contains the functioning V1 phase/workflow system. Read [the authority router](docs/context/context_authority.md) before making product or architecture decisions.
