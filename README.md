# Codize

Codize is a beginner-first AI coding mentor for students building real projects with external coding agents. Its V2 promise is: **Build something real with AI. Learn how it works as you go.**

V2 now has canonical product/UX direction, technical architecture, and an eleven-table MVP schema design, but none of that V2 system is implemented or migrated yet. The repository still contains the functioning V1 phase/workflow system. Read [the authority router](docs/context/context_authority.md) before making product or architecture decisions.
