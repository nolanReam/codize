# Codize UI/UX Research Sources

> [!NOTE]
> **Supporting research, not product authority.** Canonical V2 product/UX documents and approved Figma outrank this source set. V1 pilot findings may reveal durable usability problems without requiring preservation of V1 screens or workflow.

## Authority order

1. Accessibility and usability
2. Actual Codize pilot feedback
3. Clear task completion
4. Existing Codize product and frontend conventions
5. Established UX principles
6. Visual polish and aesthetic preference

## Core Sources

### 3 Strategies for Managing Visual Complexity

Role:
Primary cognitive-load and application-complexity source.

Use for:
- predictable placement
- clear grouping
- visual hierarchy
- reducing simultaneous choices

Do not use for:
- hiding essential state
- removing necessary workflow controls

### Progressive Disclosure

Role:
Primary progressive-disclosure source.

Use for:
- optional guidance
- advanced controls
- source details
- destructive secondary actions

Do not use for:
- hiding the primary action
- hiding required warnings
