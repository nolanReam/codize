# Source index

## Active V2 authority

1. **A1** — `docs/context/v2/codize_v2_product_thesis.md`: highest product authority.
2. **A2** — `docs/context/v2/codize_v2_exact_ux_specification.md`: behavior, state, IA, teaching interaction, copy intent, responsive/accessibility rules.
3. **A3** — `docs/context/v2/codize_v2_character_system_blueprint.md`: character/animation/customization/cosmetic subsystem only.
4. **A4** — approved Figma: visual composition, styling, sizing, component appearance, responsive layout, and motion intent only.
5. **A5** — accepted V2 decision records, if any, subordinate to A1–A4.

`docs/context/context_authority.md` is the router to this chain; it is not a competing product source.

## Current implementation sources

- **I1** — `frontend/README.md`, frontend code/tests, and rendered behavior: current V1 implementation truth.
- **I2** — `backend/README.md`, backend code/tests, migrations, and verified deployment evidence: current V1 implementation truth.
- **I3** — `.claude/memory/README.md` and classified memory files: implementation records and technical lessons.

Current V1 code matters when maintaining or migrating it. Its dark engineering-cockpit styling, phases, workflow journey, gate, Defense, and report are not V2 design authority.

## Durable research and evidence

- **R1** — `docs/ui-ux-research/codize-pilot-lessons.md`: observations from V1; useful evidence, not a mandate to preserve V1 screens.
- **R2** — `docs/ui-ux-research/source-manifest.md` and core research transcripts: general usability/accessibility references subordinate to A1–A4.

## Historical sources

The old operating brief, master product spec, V1 decision records, pilot kit, releases, archive, and V1 product memories are historical/current-implementation context only.

Do not read `conversations.json` by default.

## Conflict examples

- A current V1 component contract controls a scoped bug fix, but cannot redefine the V2 destination.
- General design advice cannot override the Exact UX or accessibility.
- Figma controls composition; behavioral changes require synchronization with A1/A2.
- A technical trust lesson may survive while its V1 screen or lifecycle disappears.
