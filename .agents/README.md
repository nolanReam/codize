# Repository agent resources

Skills in this directory are subordinate to `docs/context/context_authority.md` and the canonical V2 documents under `docs/context/v2/`.

- `spec-guardian` routes product work and prevents V1 authority drift.
- `codize-ui-ux` and `ui-ux` govern user-facing work within V2 UX/Figma authority.
- `security-test` preserves durable security, ownership, validation, provenance, and verification practices.
- `milestone-handoff` is engineering-process guidance only.

No skill may turn current V1 intake, archetypes, phases, gates, Defense, cooldowns, workflow stages, or unlock rules into V2 requirements.
